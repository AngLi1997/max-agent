# UI 改造设计文档

日期：2026-04-29

## 概述

对 max-agent 前端管理系统进行 6 项 UI 改造，涉及表格、表单、布局三个层面。前端使用 Vue 3 + Ant Design Vue 4.x + Vite，共 12 个页面，其中约 10 个页面包含数据表格。

## 改造项

### 1. 紧凑型表格

所有页面的 `a-table` 组件统一设置 `size="small"`，减少行高和内边距。

涉及页面：用户管理、角色管理、权限管理、菜单管理、系统配置、操作日志、登录日志、模型管理、技能管理、工具管理。

### 2. 操作列下拉按钮

将表格操作列中的多个独立按钮（编辑、删除等）合并为一个「操作」下拉按钮。

实现方式：
- 使用 `a-dropdown` 包裹一个 `a-button`（文案「操作」，带下拉箭头图标）
- 下拉菜单使用 `a-menu` + `a-menu-item`，每项带图标
- 删除操作保留二次确认（`a-popconfirm` 或 `Modal.confirm`）
- 操作列宽度可缩减至 80-100px

### 3. 状态 Switch 独立列

在操作列之前新增「状态」列，使用 `a-switch` 组件展示和切换启用/停用状态。

规则：
- 所有有状态字段的页面都添加此列
- Switch 开启 = 启用，关闭 = 停用
- 切换时直接调用 API 更新状态，无需打开表单
- 列标题为「状态」，宽度约 80px，居中对齐

涉及页面：用户管理、角色管理、菜单管理、模型管理、技能管理、工具管理、系统配置（如有状态字段）。

### 4. 表单状态字段默认值

新增表单：
- 状态字段（select 或 radio）不设置默认值，显示 placeholder「请选择状态」
- 前端在提交新增请求时，如果用户未选择状态，自动将状态字段设为「停用」后再提交

编辑表单：
- 正常回显当前记录的状态值，不做修改

### 5. 抽屉响应式宽度

将所有表单容器统一为 `a-drawer`（包括现有使用 `a-modal` 的地方），并实现响应式宽度：

- 屏幕宽度 ≤ 768px → 抽屉宽度 100%
- 屏幕宽度 769px ~ 1200px → 抽屉宽度 50%
- 屏幕宽度 > 1200px → 抽屉宽度 520px

实现方式：
- 创建一个 `useDrawerWidth` composable，监听 `window.resize` 事件，返回响应式宽度值
- 所有页面的 Drawer 组件引用此 composable
- 迁移现有 Modal（如角色权限分配等）为 Drawer

### 6. 浏览器风格 Tab 页

在内容面板顶部（header 下方、router-view 上方）添加 tab 栏，实现多页签导航。

功能：
- 点击左侧菜单时，如果 tab 已存在则激活，否则新增 tab
- 每个 tab 显示页面标题和关闭按钮（✕）
- 右键菜单支持：关闭当前、关闭左侧、关闭右侧、关闭其他、关闭全部
- 使用 Vue 的 `<keep-alive>` 缓存已打开页面的组件状态
- Tab 栏支持横向滚动（当 tab 数量超出可视区域时）

实现方式：
- 创建 `useTabStore`（Pinia store）管理 tab 列表状态
- 创建 `TabBar.vue` 组件，放置在 `BasicLayout.vue` 的 content 区域顶部
- 路由守卫中自动添加 tab
- `keep-alive` 的 `include` 属性绑定到当前打开的 tab 对应的组件名列表
- 各页面组件需要设置 `name` 属性以配合 `keep-alive`

## 不在范围内

- 不修改后端 API
- 不修改路由结构
- 不修改登录页和仪表盘页的布局
- 不新增页面或功能模块
